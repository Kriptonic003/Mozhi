# MOZHI Frontend

Modern React + TypeScript + Vite + Tailwind CSS interface for MOZHI voice journaling.

## Features
- **Warm Editorial Diary Aesthetic:** Styled with calming cream, lavender, and warm neutral tones for a soothing personal diary experience.
- **Web Audio API Voice Recorder:** Microphone recording with duration timer, audio waveform visualization, pause/resume, and audio file upload.
- **Transcript Editor:** Side-by-side editing of model-generated Romanized Manglish with original transcript preservation.
- **Journal Archive & Search:** Full historical search and pagination across voice journals.
- **AI Assist:** Integrated triggers for English translation, journal passage polishing, and reflection summaries.

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start development server:
   ```bash
   npm run dev
   ```

3. Open [http://localhost:5173](http://localhost:5173) in your browser.
